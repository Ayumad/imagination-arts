# Imagination Arts

The website for Imagination Arts, a playful art studio for children, teens, and adults in the Ardenwood area of Fremont, California.

**Live site:** [imaginationarts.studio](https://imaginationarts.studio)

## What’s included

- Dedicated pathways for ages 4–6, ages 7–10, ages 11–13, high school, and adults
- Camps, parties, studio story, and trial-class contact pages
- A fluid, CSS-based gallery ribbon ready for real student and art photography
- Accessible navigation, reduced-motion support, social metadata, sitemap, robots file, and `ArtSchool` structured data
- A privacy-minded inquiry flow that prepares email, text, and call actions without storing submissions

## Adding studio photos and a logo

No stock or generated photography is used. Add official photography and branding as it becomes available; the project’s [media guide](./MEDIA-GUIDE.md) describes the recommended file names, dimensions, cropping, and alternative text.

## Local development

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000). Before publishing a change, run:

```bash
npm run lint
npm run build
```

## Deployment

The production project is hosted on Vercel. Pushes to the connected GitHub repository can be used to create preview deployments and update production once Vercel’s Git integration is enabled.
